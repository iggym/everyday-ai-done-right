# Draft a Community Newsletter with a Free OpenRouter Model

- **Tool:** OpenRouter :free model variants
- **Cost:** $0 on :free variants — listed by OpenRouter as free versions of models
- **Limits:** Free variants have their own rate limits and availability; check the model page
- **Source:** https://openrouter.ai/docs/guides/routing/model-variants/free
- **Verified:** 2026-10-08
- **Guide:** https://iggym.github.io/everyday-ai-done-right/articles/openrouter-free-newsletter-drafts.html

## Steps

1. **Collect the updates.** Ask committee members to send three bullet points each by the same deadline.
2. **Pick a free model.** Use a model ID ending in :free from the OpenRouter models page.
3. **Generate the draft.** Use the prompt below. Ask for a subject line and two alternatives.
4. **Edit for names and dates.** Check every name, date, and figure against the original bullets.
5. **Save the prompt.** Keep the prompt in a text file so next month's issue has the same structure.

## Prompt

```text
Write a community newsletter from the updates below. Use: a friendly subject line plus two alternatives, a 60-word opening, sections for each update with a heading, and a closing with the next meeting date. Use only facts in the updates. Keep it under 500 words.

UPDATES:
<paste>
```

## Check your result

- [ ] Every date and name matches the bullets
- [ ] No fundraising or money figures were invented
- [ ] The subject line works without the body

## Pitfalls

- Free models can change between sessions; keep your prompt stable so tone stays consistent.
- Email lists may have data rules; send only to people who subscribed.

_The ':free' variant behaviour was read from OpenRouter's documentation on 8 Oct 2026. Free models change often; check the model's page for current limits._
