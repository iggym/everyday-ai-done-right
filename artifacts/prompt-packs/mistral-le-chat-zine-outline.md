## Steps

1. **Dump your ideas.** Write every idea on a separate line, even weak ones.
2. **Group them.** Ask for four to six themes, then choose the ones with the most material.
3. **Generate the page plan.** Use the prompt below for an eight-page outline with a headline and one image idea per page.
4. **Sketch the folds.** Draw the page plan on a folded sheet to check which pages face each other.
5. **Print a test copy.** Print one copy and read it aloud before you make the run.

## Prompt

```text
Create an eight-page outline for a printed A4 zine, folded into eight panels. For each page give: a headline, the main text in no more than 60 words, and one image or illustration idea. Put the cover on page 1 and the back cover on page 8. Use these themes: {themes}.
```

## Check your result

- [ ] Page order makes sense when folded
- [ ] Images are yours or appropriately licensed
- [ ] A printed test copy was read aloud

## Pitfalls

- Use only images you have rights to; check licences before you print.
- Keep personal details out of community publications unless the people have agreed.
