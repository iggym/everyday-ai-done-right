What this replaces

A freelance web developer charges $500 to $3,000+ for a simple landing page, depending on experience and how many revisions you need (Fiverr and Upwork ranges as of early 2025). Squarespace's cheapest plan is $16/month and still requires you to build the page yourself using their editor. Claude's free tier produces a complete first draft in under two minutes at $0 with no card and no subscription.

Will you hit the free limit?

Anthropic does not publish specific free-tier message limits for Claude. The number of messages you can send (including code-generation requests) before being throttled is not disclosed on claude.ai or in their help center.

Practical guidance: Generating a few landing pages per session, plus several rounds of edits, typically works without hitting the throttle. If you do get throttled, Claude tells you to wait — there's no countdown timer and no way to check remaining usage in advance. For a one-time task like building a landing page, the free tier is almost always enough.

Step 1 of 6

Write a short description of your business

One paragraph: who your customers are, what you sell or offer, and what makes it different from what's already out there. Don't worry about wording — rough is fine. Claude will clean it up.

Open Claude

Go to claude.ai in any browser. Create a free account with an email address — it never asks for a credit card. Start a new conversation.

Send the prompt with your description

Paste your paragraph into the prompt below where indicated, then send the whole thing to Claude:

I'm starting a small business. Here's a one-paragraph description:

[PASTE YOUR DESCRIPTION HERE]

Create a complete, single-file landing page in HTML with inline CSS. No external stylesheets, no CDN links, no JavaScript. Include: a hero section with headline and subheadline, a "how it works" section with 3 steps, a features section with 4-6 benefits, a simple pricing section (placeholder prices are fine), an FAQ section with 4 questions, and a footer with a call to action. Use a clean, modern layout, good spacing, and a professional color scheme. Make it mobile-responsive using a single media query. Output only the HTML code, nothing else.

Copy the output into a text editor

Select everything in Claude's response that starts with <!DOCTYPE html> and ends with </html>. Open any plain text editor — Notepad on Windows, TextEdit on Mac (use Format → Make Plain Text first if it's not already). Paste the code and save the file as index.html.

Open the file in your browser

Double-click the saved file. It opens as a local webpage. Read through it, note what you want to change — wrong wording, colors you don't like, a section you want to remove. Go back to Claude in the same conversation and ask for specific edits:

Change the headline to "Your New Headline Here", remove the pricing section, and make the background color dark blue.

Claude will output the updated full HTML. Replace the file contents and refresh your browser.

Put it online for free (optional)

Create a free account at github.com. Click "New repository," give it any name, check "Add a README file," and make it public. Click "Add file → Upload files" and upload your index.html. Then go to Settings → Pages, select the main branch, and click Save. Within a minute, your page is live at username.github.io/repo-name.

What breaks

  • Unpublished message limits: Anthropic doesn't disclose how many messages free-tier users can send before throttling. Generating a few pages per session usually works fine, but you may hit the limit during back-and-forth editing. When throttled, Claude tells you to wait — no countdown, no way to check how much you have left.
  • It's a starting point, not a finished product. The page will look professional at a glance but lacks polish — no animations, no responsive images, no optimized typography. It's a draft that replaces staring at a blank screen, not a replacement for a web designer.
  • No backend. The page is static HTML. Contact forms won't send emails, buy buttons won't process payments, and nothing gets saved to a database. For those, you'd need to add a service (many have free tiers, but that's a separate setup).
  • Editing requires touching HTML. You can ask Claude to make changes and paste the updated code, but if you want to tweak a word yourself without going back to Claude, you're editing raw HTML. A text editor and basic find-and-replace handle most of this, but it's not a visual editor.
  • "Inline CSS only" limits the design. The prompt asks for inline CSS to keep everything in one file. This works well for simple layouts but won't produce the kind of design you'd get from a real CSS framework or a website builder.

Three things this guide teaches

Without the "no external stylesheets, no CDN links" instruction in the prompt, Claude sometimes references Tailwind CSS via a CDN or links to Google Fonts. Those work when you're online but break the moment you open the file without internet. For a single-file page you can email to someone or open offline, everything needs to be self-contained. The inline-CSS constraint is what makes the output a genuinely portable file.

SCORE (score.org) is a nonprofit backed by the SBA that pairs you with a free volunteer mentor — usually a retired executive or experienced entrepreneur. Most side-hustlers have never heard of it. After Claude generates your landing page, you can book a free SCORE session and have a real person review your messaging, value proposition, and page structure. An AI can generate the page; a human who's built businesses can tell you whether the message actually sells.

Claude generates HTML from learned patterns about web design, not from a fixed template library. The same prompt will produce a meaningfully different page structure each time — different section ordering, different heading hierarchy, different ways of laying out the features grid. Run it two or three times, open each result, and pick the structural foundation that fits your business best before spending time on edits. This costs extra messages but the free tier almost always has enough headroom for it.
