The Walkthrough

Step 1: Open Claude

Go to claude.ai and log in with a free account. No payment method is required.

Step 2: Describe Your Tool

Paste the prompt below, customizing the brackets to describe the specific tool you need:

Write a single-page HTML app with embedded CSS and JS for this purpose: [Describe your tool, e.g., 'A calculator that converts my dog's weight in lbs to medication dosage in ml, accounting for concentration']. Make the UI clean and modern. Put the code in an Artifact.

Step 3: View the Live Artifact

Wait a few seconds. The code will appear in the right-hand Artifacts window, fully rendered and interactive. You can use it immediately.

Step 4: Refine or Export

Ask for changes in plain English (e.g., "make the buttons blue"), or click the copy icon in the Artifact to save the HTML file locally so it runs forever without internet.

What Breaks

You cannot save the app to a custom URL directly from the free Claude UI (you can bookmark the chat or copy the code). Very complex apps (like multi-page sites or database backends) will fail—this works best for single-page calculators, trackers, and visualizers. Free tier message limits apply (roughly 10-15 messages per 8 hours).

Three Things This Teaches

Explicitly asking Claude to put the code in an Artifact forces it to use its rendering environment, giving you a live preview instead of just dumping a text file of code.
You can say "make the buttons bigger" or "add a dark mode" without understanding CSS; the AI rewrites and refreshes the Artifact instantly.
Even though it runs in the chat, you can click "copy code" and save the HTML file locally—it runs forever without an internet connection or AI subscription.
