⚠️ What Breaks

Groq's free playground tier operates under strict requests-per-minute (RPM) and tokens-per-minute (TPM) limits. If you paste massive multi-hundred-page textbooks in a single request, you will trigger token length boundaries or rate throttles.

Three Things to Know

1. Token vs. Request Limits +
Free hardware inference tiers enforce strict per-minute token caps. Submitting overly bloated text blocks causes rate limits faster than submitting concise, single-chapter chunks.
2. Pedagogical Prompting +
Structuring prompts to request Socratic questions rather than simple bullet summaries dramatically improves long-term retention during self-study.
3. Open Model Flexibility +
Groq's playground lets you swap between leading open-weights models instantly without paying subscription tiers or updating API billing methods.
