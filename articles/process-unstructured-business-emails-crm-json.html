Step-by-Step Walkthrough

1

Open the Workers AI Playground

Navigate to ai.cloudflare.com and log in with your Cloudflare account. No credit card is required to register or use the playground.

2

Select Open-Weights Llama Model

Select @cf/meta/llama-3-8b-instruct from the model picker. This fast open-weights model executes structuring tasks in under a second.

3

Apply System Extraction Prompt

Paste the system prompt below into the playground configuration box:

SYSTEM PROMPT:
You are an automated Business Operations Parsing Engine.
Your task is to take unformatted, messy client inquiry emails and extract specific operational data fields.
Always output strict, valid JSON without conversational wrapper text, markdown formatting blocks, or preamble.

Required JSON Structure:
{
  "client_name": "Full Name or 'Unknown'",
  "company": "Company Name or 'Not Provided'",
  "contact_email": "Email Address or 'Not Found'",
  "service_requested": "Core Service/Product Requested",
  "urgency_level": "High | Medium | Low",
  "budget_mentioned": "Numeric value or 'Unspecified'",
  "action_items": ["Array of concise required follow-up actions"]
}
4

Execute & Export JSON

Paste your raw customer email into the user prompt field and click Run. Copy the JSON result straight into your database or spreadsheet.

What Breaks (Limitations)

  • 10k Daily Neuron Cap: Resets daily at 00:00 UTC. Unused quota does not roll over.
  • No Native GUI Webhook: Web UI is manual copy-paste; automated backend pipelines require free API token setup via Cloudflare REST API.
  • Context Floor: Massive email threads (>8,000 tokens) will be truncated.

Three Keys to Maximizing Free Edge AI

1. Use 8B Parameter Models for Data Tasks +
Smaller instruct models like Llama 3 8B consume far fewer neurons per request, tripling your effective daily output volume compared to larger models.
2. Enforce Strict JSON Schema +
Providing explicit field names and fallback values ('Unspecified') prevents model hallucination and ensures machine-parsable outputs.
3. Zero Credit Card Safety Net +
Because Cloudflare's free tier does not request billing info, you can never accidentally trigger surprise API overage charges.
