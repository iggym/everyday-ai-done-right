Walkthrough — interactive stepper

Prompt templates (one-click copy)

Create a 3-level study system from my sources:

LEVEL 1 - Map: List the 12 core concepts with 1-sentence definition each, citing source file and page.
LEVEL 2 - Test: For each concept, write 2 recall Qs (answer hidden) + 1 application Q.
LEVEL 3 - Gaps: Flag 3 topics where sources conflict or are thin, and tell me what to add.

Constraints: Use ONLY my sources. If info missing, say "Not in sources".
Generate exam-ready artifacts:

1. Study Guide: 800 words max, grouped by theme, with inline citations [Source Name].
2. 20 Flashcards: Front = question, Back = answer + 5-word mnemonic.
3. 10 MCQ: 4 options, mark correct, explain why others wrong, cite source.
4. Audio script: 5-min podcast outline for "Explain like I'm teaching a friend".

Format flashcards as CSV: Question,Answer,Mnemonic,Source

What Breaks — coral callout

  • Free cap: 50 sources/notebook — if you have 70 PDFs, split into 2 notebooks (e.g., Ch1-5, Ch6-10). You still get 100 notebooks total free.
  • Audio limit: 3 Audio Overviews per day — queue them. Write script first, then generate overnight.
  • 500k words per source — huge scanned PDFs (>500 pages) may need OCR split. Use Google Drive Docs OCR (free) before upload.
  • Hallucination guard only works if you prompt "Use ONLY my sources" — otherwise it may blend Gemini world knowledge.
  • No API key for free chat? It's web-only. Export via copy/paste or Download as Google Doc.

Three Things to Try Now — click to reveal

1. Podcast your lecture notes while commuting
Upload lecture slides + your handwritten notes photo. Hit Audio Overview → get 8-min dialogue podcast grounded in your material. Listen offline in NotebookLM app. Limit 3/day, so batch 3 subjects each morning.
2. Turn YouTube lectures into self-testing Q&A
Paste YouTube URLs as sources (NotebookLM auto-transcribes). Then prompt template #1 — instant quiz from 10 videos without manual notes.
3. Spaced repetition export
Copy flashcard CSV → import to Anki (free, open source). You get grounded cards with source citations — no made-up facts.
