Step-by-step — 4 minutes

Copyable prompt templates

Use in Groq Playground (free, no card) or API. Model: llama-3.3-70b-versatile. Temperature 0.2 for SOW.

1) Inbox → Structured Brief

You are a business analyst. Extract from CLIENT_BRIEF below: Return JSON with keys: - goal (1 sentence) - audience - must_haves array - nice_to_haves array - constraints {deadline, budget_range, tech_stack, compliance} - missing_info array (ask 3-5 questions) - red_flags array (scope creep risk, etc.) Rules: No hallucinating dates/prices. If not mentioned, use null. Keep must_haves <10. CLIENT_BRIEF: [paste email thread] Output only valid JSON.

2) Brief JSON → Proposal + SOW

Using BRIEF_JSON, write client-ready proposal in Markdown: # Sections: 1. Executive Summary (3 bullets, outcome-focused) 2. Scope — In Scope table (Feature | Description | Acceptance Criteria) 3. Out of Scope (explicit list to prevent creep) 4. Timeline (Week 1-2: Discovery etc., assume start next Monday unless date given) 5. Deliverables checklist 6. Risks & Mitigations 7. Pricing placeholder table (do NOT invent prices, use [YOUR RATE] unless budget given) Style: concise, no buzzwords. Insert [NEED: ...] wherever info missing. Add disclaimer: "Estimates based on provided brief, no browsing." BRIEF_JSON: [paste JSON from Prompt 1]

3) SOW + Pricing Table CSV

Convert SOW into pricing table CSV for import to Sheets. Columns: Item,Type (Fixed/Hourly),Qty,Unit Price,Line Total,Notes Rules: - If budget given, allocate to sum <= budget *0.9 (leave 10% buffer) - If no budget, use Unit Price = [YOUR RATE] placeholder - Include 3 options: Basic, Standard (recommended), Premium with 1 upsell line each - Last row: Total, contingency 10%, grand total - Output CSV only, comma-separated, with header. SOW: [paste SOW markdown]

What Breaks — Limitations

  • Quotas: Llama-3.3-70B free: 30 RPM, 1000 RPD, 12K TPM, 100K TPD (source: Groq docs + Grizzly March 2026 table). Binding is usually TPD: 100K ≈ 50 proposals of 2K tokens. Resets 00:00 UTC daily. Upgrade to Developer tier (card) removes daily cap.
  • No browsing / no file upload in playground: You must paste brief. Model cannot fetch Google Docs link, so copy-paste text.
  • Hallucination risk: If you don't give rates, it may invent $150/hr unless you use placeholder rule in prompt 2. Always keep [YOUR RATE].
  • Context 128K but TPD limits: You can paste 100-page brief but tokens count toward 100K daily — one huge brief = 30% of daily TPD.
  • Privacy: Groq free tier processes prompts on US cloud; don't paste PII, secrets, or client credentials. Redact emails to initials.
  • Not legal advice: SOW template is not legal contract; have lawyer review liability, IP clauses.
