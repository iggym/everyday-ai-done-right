Walkthrough — interactive stepper

Copyable action checklist (one-click copy)

PHOTOPEA PRO PRODUCT PHOTO — 4 MIN FLOW
1. Open photopea.com → File → Open → phone.jpg
2. Select → Select Subject (AI). Wait 3s.
3. Select and Mask → Feather 0.5, Shift Edge -10%, Refine hair.
4. Layer → New → Layer via Copy (Ctrl+J) → Delete original background layer
5. File → New → 2000x2000 white background → drag subject layer in
6. Layer → Layer Style → Drop Shadow: Opacity 18%, Distance 30, Size 40
7. Image → Image Size → 2000px width → check "AI upscaling" if small
8. File → Export As → PNG or JPG Quality 90 → Save
BATCH WHITE-BACKGROUND PROMPT FOR 20 IMAGES
- Record Action: Window → Actions → New Action "WhiteBG"
- Perform steps 2-6 once, then Stop Recording
- File → Automate → Batch → Source: Folder, Action: WhiteBG, Destination: Folder
- Result: 20 clean PNGs in <2 min, no account, free

What Breaks — coral callout

  • Browser RAM limit: >50MP RAW files can crash tab — downscale first to 4000px long edge.
  • Ads in UI: free tier shows small ad panel — does not affect export, can be dismissed.
  • AI Select Subject struggles with translucent objects (glass, lace) — use Magic Wand + Refine Edge manually.
  • No cloud save — save PSD to device, or you lose work on refresh.
  • AI upscaling is not generative — it sharpens, doesn't invent detail. For true generative fill, need Photopea Premium ($3.33/mo) — not required for this workflow.
