The walkthrough

Set it up before you need it

Step 1 of 5

Start Live Captions

Press Windows + Ctrl + L. The first run may ask you to consent to on-device voice processing and download speech-recognition language files. Finish that setup before depending on it for a meeting, class, or appointment.

If the shortcut does nothing, go to Start → All apps → Accessibility → Live captions, or open Settings → Accessibility → Captions.

Step 2 of 5

Choose the right audio source

For a meeting, video, podcast, or browser tab, leave microphone audio off. Live Captions reads audio passing through the PC.

For an in-person conversation, open the caption window’s Settings menu, choose Preferences, then enable Include microphone audio. System audio has priority if both are active, so it may not transcribe both sides of an overlapping call cleanly.

Step 3 of 5

Put the text where it helps

Use the caption window’s Settings → Position menu. Pick Above screen for meetings or shared screens, Below screen for many videos, or Floating on screen when you need to move it around content.

Use Preferences → Caption style to choose a style that is easier to read. Make the window taller if you need more visible lines.

Step 4 of 5

Save a repeatable setup note

Copy this into Notes, OneNote, or a calendar reminder before an important conversation.

Live Captions setup:
1. Press Windows + Ctrl + L.
2. Confirm captions appear before the speaker begins.
3. Use system audio for calls and videos.
4. Turn on microphone audio only for in-person speech.
5. Put captions above screen if they cover shared content.
6. If captions lag, close unused apps and remove video background effects.
Step 5 of 5

Run a low-stakes test

Play 30 seconds of spoken video, press Windows + Ctrl + L, and move the window. If captions lag or drop, close unused programs and reduce video effects. This test catches setup problems before a conversation where you need the text.

What breaks

Captioning is support, not a record

Live Captions recognizes speech, not every sound. Music, applause, and other audible events are not captioned; sung lyrics are not reliably captioned. Fast speech, technical terms, background noise, and speakers talking over each other can produce mistakes.

Resource-intensive apps can cause delayed or dropped captions. For high-risk or emergency information, confirm important details with the speaker or another trusted source. The tier-specific limit is hardware and software: you need Windows 11 version 22H2 or later; translation has separate Copilot+ PC requirements.
