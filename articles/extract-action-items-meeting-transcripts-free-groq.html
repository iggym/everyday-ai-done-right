🛠️ Step-by-Step Implementation

1
Open Groq Cloud Developer Playground

Go to console.groq.com/playground and sign in with Google or Email. No credit card required.

2
Configure Model Settings

Select model llama-3.3-70b-versatile from the dropdown. Adjust temperature slider down to 0.2 for high structural accuracy.

3
Paste System Extraction Prompt

In the System Instruction box, paste this structured parser prompt:

You are an executive operational assistant. Your job is to extract precise, objective structured information from raw meeting transcripts. 
Do not summarize general chatter. Extract ONLY:
1. DECISIONS MADE (Explicit agreements reached)
2. ACTION ITEMS (Task description, Assigned Owner, Hard Deadline if mentioned, Dependencies)
3. OPEN QUESTIONS (Unresolved items requiring follow-up)
Format the output as clean Markdown tables. If information (like a deadline or owner) is not explicitly stated in the text, write "Unassigned" or "Not specified"—do not guess.
4
Paste Raw Transcript & Submit

Paste the raw unformatted transcript from Zoom, Teams, or phone recorder into the user input box and hit Submit. Output is generated in 2–4 seconds.

⚠️ What Breaks (Exact Limitations)

  • 6,000 Tokens/Min Ceiling on 70B Model: Transcripts over 45 minutes (~4,500 words) exceed single-pass token rates. Solution: Process in two halves or select llama-3.1-8b-instant (100k TPM).
  • Text-Only Input: Audio file uploading is not built into the playground. You must copy/paste text from captions or pre-transcribe audio.
  • Unredacted Sensitive Data: Avoid pasting raw credit card numbers or unencrypted user passwords into public playground prompts.

💡 Three Rules for Flawless Transcripts

Higher temperature causes LLMs to invent deadlines or assume owners based on contextual hints. Keep temperature at 0.2 so missing facts are tagged explicitly as "Unassigned".
For hour-long board meetings, feed transcript chunks section by section. This avoids hitting token rate limits while giving higher fidelity for action item assignments.
Use Windows 11 Live Captions or macOS Live Captions to generate instant, local text transcripts of any WebEX, Google Meet, or phone audio for $0 before running this prompt.
