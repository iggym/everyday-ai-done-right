Step-by-Step Walkthrough

1 Stop. Do not install Automatic1111.

Scar-Tissue Confession: I spent a week fighting with the wrong interface, crashing my system, and wondering why my generations were so slow. The standard recommendation is to install the Automatic1111 WebUI because it's the most popular. That is the trap.

So What? If you ignore this and install Automatic1111 on a 4GB GPU, you will waste 30 minutes waiting for it to load only to get an "out of memory" error. (As of 2026-08-20, this is the #1 complaint in support forums.)

2 Install ComfyUI instead.

Why? ComfyUI is more efficient with VRAM and allows you to build complex workflows visually. It's the tool used by professionals.

Download from: github.com/comfyanonymous/ComfyUI
  • Windows: `ComfyUI_windows_portable` .zip
  • Mac: `ComfyUI_macos` .dmg
  • Linux: `install.sh` script
3 Download a Model (Checkpoint)

ComfyUI is a framework; it doesn't come with an image model. You must download a checkpoint file.

  1. Go to Civitai.com.
  2. Search for "Realistic Vision" or "DreamShaper" (great starter models).
  3. Download the `.safetensors` file.
  4. Place it in: ComfyUI/models/checkpoints/.
ComfyUI/models/checkpoints/
4 Run ComfyUI & Queue Prompt

Verify it works. This is the most important step. If you skip this, you'll waste time tweaking settings that don't exist.

  • For Windows, run run_cpu.bat (if no GPU) or run_nvidia_gpu.bat.
  • It will open a browser window to localhost:8188.
  • Click "Queue Prompt" once to generate a sample image.

So What? Getting that first image generated proves your pipeline works. Skipping this means you'll be troubleshooting a broken configuration for hours.

⚠️ What Breaks (Limitations)

  • VRAM: The "Simple" workflow will crash on a 4GB GPU. You must use the `--lowvram` flag or use a lightweight model.
  • The Node Interface: If you are looking for a classic Photoshop-like UI, you will hate this. It is not "friendly." So what? The initial frustration is a tax you pay for having zero recurring costs and unlimited generations.

🔑 Three Things I Wish I Knew

  • 1. The UI is not the model. You can swap models in and out. Don't blame the UI for bad images; blame the checkpoint.
  • 2. Negative prompts are more powerful than positive ones. Telling the AI what you *don't* want is often more effective.
  • 3. `cfg_scale` matters. A value of 7 is standard. Going to 12 makes it more obedient but less creative. Going to 3 makes it a 'creative' mess.
